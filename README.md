**CloudBase尚未授权、未创建环境或部署函数，真实云数据库和手机网络未验收，当前网页AI仍未接通。** CloudBase CLI已通过npm官方包运行，第一次设备码授权未完成并已过期；没有切换到永久密钥登录。不要将“代码已适配”视为“已经上线”。

CloudBase额度用私有集合`persona_budget_v1`的单个文档保存全站计数和至多100个派生浏览器标识，通过事务一起提交，避免双计数不同步。文档缺失、结构不一致或更新失败时停止模型请求。Node SDK使用裸字段update参数，已通过实际SDK序列化检查；事务并发测试目前使用本地乐观事务模拟，不能替代真实云端验收。

部署时必须检查环境类型支持当前文档数据库事务、集合对客户端禁读写、函数角色权限、实际免费资格和费用。`cloudbaserc.template.json`只有模板，没有真实环境ID，不可直接当作部署成功记录。HTTP网关仅指向`wmamba-persona-api`，前缀`/persona`；按实际网关验证路径透传、预检、安全域名和匿名访问，不公开管理函数。

`wmamba-budget-import`仅供站长在受控部署流程中内部调用，还必须配置单独64位十六进制`MIGRATION_SECRET`；既检查内部调用形态，也校验管理密钥。该密钥不写入源码、前端或本仓库，不给公开API函数配置。额度快照不入库。先冻结旧模型入口再导入原100次池，导入后仍暂停，核对后才内部启用。不要启用两个独立收费入口或新建100次额度。

API配置现在支持官方CloudBase网关的HTTPS地址及`/persona`前缀，仍默认空值。正式默认域名限制和自定义域名要求参考：https://docs.cloudbase.net/service/introduce 。账户接通后先测试实际接口，不承诺默认域名长期可用于生产。

## 后端

`backend/` 是可迁移的Node.js API。DeepSeek密钥只配置在托管平台服务端。数据库采用PostgreSQL持久事务，全站原100次池及每浏览器约10次限制在服务端计数。数据库或已迁移额度缺失时暂停AI，不自动初始化100次、不使用进程内或浏览器计数替代全站预算。

`render.yaml` 是候选试用配置，尚未执行：Render免费网页服务会休眠，免费数据库30天到期，不能当作长期生产托管承诺。须先确认账号、实际费用及手机网络能访问后端。数据库到期时额度校验失败，AI暂停，不重置预算。参考：https://render.com/docs/free 。

## 切换顺序

1. 接通托管账号，确认域名、费用与持久数据库。
2. 部署后端，`PERSONA_AI_ENABLED=false`，配置准确的`APP_PUBLIC_ORIGIN`；前端允许来源固定为`https://wmamba0824.github.io`。
3. 冻结旧站模型生成，取得完整的已用次数和浏览器派生计数快照。私密快照不提交本仓库。
4. 运行`node import-budget.mjs /private/snapshot.json --old-site-frozen`导入；已有池时拒绝覆盖。新池至少保留先前已用1次，实际切换时以冻结后的实时记录为准；旧5次单独保留审计。导入后仍暂停，需管理员确认再启用。
5. DeepSeek密钥只存服务端密钥区。完成数据库检查后启用新后台，并配置`docs/config.json`中的正式API地址。该版本只允许HTTPS的`*.onrender.com`接口；其他提供商需同时审查客户端白名单、CSP及后端来源设置。
6. 验证匿名请求、预检、全站及浏览器限额、多实例并发、失败计数与真实回答，手机普通5G及微信测试通过后，再更新公众号入口。

浏览器随机标识只代表同一浏览器，清除存储或换设备可能重新计数，不能宣称严格每人10次。页面问题和对话只在内存中保存。

GitHub Pages只托管静态内容，不能运行上述后端：https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages 。
